# Notendurchschnitts-Rechner (Python)

## Beschreibung

Ein einfaches Python-Projekt zur Berechnung des Notendurchschnitts.

Der Benutzer gibt eine beliebige Anzahl von Schulnoten ein. Das Programm berechnet daraus automatisch den Durchschnitt und gibt eine passende Leistungsbewertung aus.

---

## Funktionen

- Eingabe beliebig vieler Noten
- Automatische Berechnung des Durchschnitts
- Ausgabe mit zwei Nachkommastellen
- Einfache Leistungsbewertung

---

## Lernziele

Dieses Projekt zeigt den Umgang mit grundlegenden Python-Konzepten:

- Variablen
- Listen
- Schleifen
- Bedingungen (if / elif / else)
- Benutzereingaben
- Mathematische Berechnungen

---

## Voraussetzungen
