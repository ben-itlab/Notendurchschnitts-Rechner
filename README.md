# Notendurchschnitts-Rechner

## Beschreibung

Ein einfaches Python-Projekt zur Berechnung des Notendurchschnitts.  
Der Benutzer gibt beliebig viele Schulnoten ein. Das Programm berechnet daraus automatisch den Durchschnitt und gibt eine passende Leistungsbewertung aus.

## Funktionen

- Eingabe beliebig vieler Noten
- Automatische Durchschnittsberechnung
- Ausgabe mit zwei Nachkommastellen
- Einfache Leistungsbewertung

## Voraussetzungen

- Python 3.x

## Programm starten

1. Terminal öffnen
2. In den Projektordner wechseln
3. Befehl ausführen:

```bash
python notenrechner.py
